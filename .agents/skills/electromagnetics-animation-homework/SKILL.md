# 电磁场与电磁波动画作业

制作可直接播放和提交的中文课程动画。沿用用户最终确认的要求，新的明确要求优先于本 Skill 的默认值。本次作业的标题、成员、参考书与分镜是实例配置，不强制用于其他班级或其他主题。

## 制作约束

- 使用 Manim Community；本模板经过 Manim 0.20.1 验证。
- 纯黑背景；白灰图像，少量浅蓝用于强调。简洁、美观、科研风格，去掉冗余图标与装饰。
- 借鉴 3Blue1Brown 的几何解释、动态场图及连续转场方式，独立设计讲稿、场景和分镜，不复刻其视频内容或素材。
- 图像要表达变化：移动点、场矢量、曲线、通量、环量和传播过程应与说明同步。保留必要的数学动画，不把“科研风格”理解为静态页面。
- 成片采用中文字幕和低音量纯器乐 BGM，默认没有旁白、没有课后练习。早期男声配音方案已被后续要求替代。
- 紧凑但可读：按字幕实际阅读量确定每段时长，转场计入该段时间；不要在解释结束后长时间停留。本实例约 118 秒，开场与片尾各约 4 秒，正文通常约 4.5–6.5 秒，复杂物理过程可适当加长。
- 所有公式、变量、上下标、偏导和数学运算符采用 LaTeX；中文与公式混排，不能直接用普通 `Text` 显示 `J_f`、`J_d` 等源码。分镜与最终视频都要检查。
- 数学入门内容与电磁学例子结合，说明适用条件，避免将二维示意或特定平面波性质推广到任意电磁场。
- 大标题、副标题和成员置于开场；参考资料只在最后一幕出现，标题为“参考资料”，采用正式编号著录，不标书籍的具体章节。

## 使用资料与模板

制作本次“梯度、散度、旋度介绍”或复刻其要求时，读取 [references/assignment-profile.md](references/assignment-profile.md)，其中记录准确标题、成员、色彩、字幕节奏、分镜与配乐参数。

核对图像和公式时，读取 [references/mathematics-and-physics.md](references/mathematics-and-physics.md)。其中包括真实抛物面、梯度轨迹、闭合曲面积分、旋度极限与正交平面波的约定。

整理片尾时，读取 [references/bibliography.md](references/bibliography.md)。以版权页或出版社、作者所在学校的书目为依据，区分版次、出版年和重印年。

渲染、修订与交付时，读取 [references/production-and-qa.md](references/production-and-qa.md)，尤其关注中文路径、LaTeX 混排、实际帧验证和旧视频文件被占用的问题。

新建同主题项目时，可将 [assets/project](assets/project) 中的源文件复制到用户指定的工作目录。它是本次作业的可运行参考模板，包含动画、字幕、BGM、渲染和检查脚本；先调整实例信息与内容，再渲染。已有项目应直接修订其源文件，不用模板覆盖用户已有修改。

## 执行与验收

1. 确认实际项目目录、当前源码、字幕、成片和用户指出的位置。若有旧版本，先识别哪个文件被播放。修改 `vector_calculus.py`、`narration.json` 等源文件，不直接修改 `media/Tex/*.tex` 哈希缓存。
2. 先形成正确的几何或物理模型，再组织分镜。需要全流程介绍时，按“概念与几何 → 局部定义 → 坐标表达 → 电磁学例子 → 总结与参考资料”衔接；内容简短时不机械扩展章节。
3. 核对数学排版与图像相互一致。动态箭头、标签和轨迹应在同一更新函数中绑定；不能只在静帧里把标签移到正确位置。
4. 渲染相关分镜预览，查看实际图片；修订模板或全片排版后检查全片。发现混排基线、下标、遮挡或过密问题，修改源码并重新检查。
5. 导出完整的 1080p、24 fps 配乐视频、封面、SRT、时间线与验证结果。其他分辨率、帧率和格式以用户指定为准。BGM 长度匹配实际视频，字幕时间线匹配编码结果。
6. 对交付文件抽帧验证，检查数学符号、字幕、运动和音轨；几何约束用数值检查与像素检查结合。不要仅凭源码或预览宣称成片已修复。
7. 使用清晰的新文件名交付修订版本，例如 `LaTeX修正版_v4.mp4`。遇到文件占用，保留旧文件并验证独立新文件，不关闭用户的播放器。最终链接必须指向实际验证过的版本，并提供有助于核对问题的成片截图。

不要把本 Skill 当作自动发布到 GitHub、替换其他项目或上传视频的授权；仅在当前任务明确要求时执行相应外部操作。
