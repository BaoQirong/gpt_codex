# 电磁场与电磁波动画作业 Skill

可复用的 Codex Skill：制作或修订科研风格的电磁学 Manim 字幕动画，涵盖梯度、散度、旋度与课程物理例子、规范 LaTeX、配乐和实际成片检查。

入口位于 [SKILL.md](.agents/skills/electromagnetics-animation-homework/SKILL.md)。同目录包含实例配置、数学与物理约定、正式书目、制作与验收说明，以及经过验证的轻量 Manim 项目模板。

克隆此仓库后，可在仓库工作区调用 `$electromagnetics-animation-homework`。也可将 `.agents/skills/electromagnetics-animation-homework` 整个目录复制到 Codex 的个人 skills 目录后使用。

示例：

```text
使用 $electromagnetics-animation-homework，为电磁场与电磁波课程制作梯度、散度、旋度的入门动画。
```

Skill 保留本次作业的准确标题、成员和书目作为可替换的实例配置；后续用户的明确要求优先。仓库包含原创工程源文件与书目链接，不包含教材全文、第三方视频素材或渲染缓存。
